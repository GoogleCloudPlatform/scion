# Runtime orphan report (ptone/scion#7930)

Phase 3 of ptone/scion#7869: the Hub records runtime objects that no Hub agent owns. It only reports them; nothing is stopped or deleted.

- **Heartbeat:** `AgentHeartbeat.AgentID` (`agentId`) carries the entry's Hub agent ID. The broker takes it from `AgentInfo.ID`, else from the `agent_id` label. An older broker omits it, and the Hub then matches by slug only. That reads a reused slug as matched, which is the safe direction.
- **Classification** (`pkg/hub/runtime_orphans.go`): the per-agent heartbeat loop collects the entries it could not match to an agent of the broker. It also collects entries whose agent ID differs from the agent their slug matched; those are still applied to that agent as before. `recordRuntimeOrphans` runs after the loop and only for targets in `completeTargets()`. Its order is: unlabeled (no project or slug, or project `default`), then unknown_project, then the live slug match (superseded, other_broker, or matched), then the agent-ID lookup (deleted, other_broker, no_agent). Agents that hold a delete (`DeletionHoldsRow`), have a queued start (`pendingStarts`) or have an in-process lifecycle op are skipped.
- **Store:** additive `runtime_orphans` table (`pkg/ent/schema/runtimeorphan.go`). It adds a `missed_inventories` column beyond the design's column list, so resolution survives hub restarts and replicas. The `action_*` columns exist but nothing writes them yet; a later phase (ptone/scion#7933) needs no migration.
- **Surfaces:** one warning per new row (`RecordRuntimeOrphans` returns the created rows); the `scion.hub.runtime_orphans` gauge reads grouped counts from the store at collection time; `GET /api/v1/admin/runtime-orphans` uses `hub.health.read` and is session only.
- **Gotchas:** `CreateAgent` ignores deletion fields, so tests set a delete in flight with `UpdateAgentDeletion`. The broker reports entries without a project under the project ID `default`. In zsh, a variable holding an `env -u ...` command is not word-split, so use a bash script for the agent-safe gates.
