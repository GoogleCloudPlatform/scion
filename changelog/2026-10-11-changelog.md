# Release Notes (2026-10-11)

The CLI's local-only mode started to go away: a repo links to the local workstation Hub, and Hub-check hints no longer suggest disabling the Hub. Agent starts now fail closed when credentials, environment settings or harness auth cannot be satisfied. Behind the conduit experiment, users gained `scion tunnel` to agent ports and SSH. Agents now report an "initializing" activity and hold messages until the harness is ready.

## ⚠️ BREAKING CHANGES
* **Local-only CLI mode removal begins** (#3227, #3287, #3277): With no Hub configured, `scion hub link` prints one line pointing to `scion server start` or a Hub endpoint. A repo links to the local workstation Hub without prompting. `scion hub unlink` only clears the link and no longer turns the Hub off, and Runtime Brokers ignore `hub.enabled`. `scion delete --cleanup-only` replaces the old `scion --no-hub delete` recovery path. Importing local agents adopts running ones and leaves idle ones stopped.
* **Agent starts fail closed** (#3271, #3297, #3352): Create, start, restart and reincarnate answer 503 when the Hub cannot resolve an agent's configured credentials or read its stored environment settings, instead of starting without them. A Runtime Broker start whose env-based harness auth cannot be satisfied fails before any container is created. The error names the harness, the auth type and the expected env keys, never values. Auth types that declare `required_files` are never rejected.
* **PostgreSQL schema shadow guard** (#3236, #3319): The Hub refuses to start, and standalone migration commands refuse to run, when the current schema has no Hub tables but a later schema on the `search_path` does. Fix the `search_path`, or set `server.database.allow_shadowed_schema` to log a warning and continue.
* **GCP service account delete refused while in use** (#3231): Deleting a registered service account that project, per-profile or Hub defaults still reference answers 409 `sa_in_use` with an impact report. `?force=true` (CLI `--force`) clears the project and per-profile defaults the caller may update, but never the Hub default.
* **Last access-constraint admin protected** (#3301): Suspending or deleting a user who is the last active access-constraint admin of a scope answers 409. Suspended users no longer count as admins.

## 🚀 Features
* **User tunnels over conduit** (#3203, #3295, #3318, #3292, #3331): Behind `hub.conduit`: `POST /v1/tunnels` opens TCP, PTY or SSH tunnels to agents over one conduit session. `scion tunnel <agent> (--port N | --ssh) [--stdio]` exposes them on a 127.0.0.1 listener or stdin/stdout, and `scion tunnel status [--json]` lists running tunnels. `sciontool` adds an embedded SSH server (shell, exec, sftp, loopback forwarding) reachable only through conduit. The Hub serves a per-launch SSH host key as `sshHostKey`.
* **Conduit session lifecycle** (#3274, #3265, #3270, #3280): Agents refresh credentials in band with `AuthRefresh`. A Runtime Broker's conduit sessions close with 4401 when it is deregistered or its secret is rotated or deactivated. An RPC that cannot be encoded fails alone instead of ending the session. `server.hub.conduit.shutdown_grace` fits the SIGTERM drain to the platform's shutdown grace.
* **Agent readiness** (#3332, #3284): Agents report activity "initializing" (shown as "starting") until the harness accepts input. Chat, DMs and wake buffer messages until then, and buffered messages are pasted only after the harness confirms readiness, so early messages are no longer lost. `scion start --wait-ready` waits for readiness, exiting 3 on timeout.
* **Kubernetes GCP identity** (#3220, #3219, #3285, #3282, #3231): The per-account status view shows each Kubernetes profile's mapped KSA, namespace, source and report age, and says "not mapped" only when the report is complete and fresh. The create and configure pickers label each service account with its mapping state for the selected target. Register, verify and delete write audit events.
* **Settings apply live** (#3293, #3249, #3244, #3304): Saved Layer-1 settings such as soft-delete retention, notification channels and image registry apply without restart. The save response lists `applied_keys` and `pending_restart`. Workstation PUTs validate conduit and port proxy blocks with 422. Admin pages show validation errors next to the field and offer Reload on a revision conflict. The GitHub App card sends explicit clears.
* **Workstation setup** (#3277, #3212, #3226): `scion server start` opens onboarding based on the Hub's onboarding status. Without `image_registry`, the Hub and web still come up and the Runtime Broker is skipped. Co-located agents can use the harness login files from the user's home (built-in harness configs only, with path guards). Start and restart recreate a missing agent's workspace inputs, so a stopped agent comes back without its old container.
* **Stranded run adoption** (#3247): When a Runtime Broker's heartbeat reports only an older run the Hub issued a token for, the Hub adopts it after a quiet period.
* **Server shutdown** (#3291, #3256): `scion server stop` waits up to 30 s for the process to exit and keeps the PID file on timeout. SIGTERM runs the same graceful shutdown as SIGINT, and a Hub startup failure exits 1 after flushing logs.
* **Kubernetes diagnostics** (#3351, #3266): Kubernetes create failures keep their cause (`k8s_reason`, `cause_code`). The Runtime Broker warns when `workspace_storage.nfs.uid` is set to a value Kubernetes ignores.
* **Cloud Logging losses** (#3233): Write losses are counted on `scion.logging.write.failures` (`writer=cloud`), with a circuit-open gauge, a non-critical `/healthz` key and alert policies.
* **Artifacts, experimental** (#3363): Behind `hub.artifacts`: `DELETE /api/v1/artifacts/{id}` and `scion artifact delete`, and responses flag artifacts whose owner was deleted.
* **Chat** (#3205, #3210, #3257, #3228, #3286, #3323, #3234, #3317, #3347, #3275): Pull to refresh on the spaces rail, a keyboard Refresh item, and a stale stream reconnect after a mobile PWA resumes. The unread badge matches the rail and counts only spaces you belong to. The members column drops the All/Unread switcher. The Hub view loads 100 recent users and searches the rest on demand. Every palette shows the agent's project slug.
* **CLI messaging wording** (#3290): `scion message` says "accepted" instead of "delivered" until delivery is confirmed. Exit codes and JSON are unchanged.
* **Groundwork** (#3211, #3258, #3263, #3320, #3260, #3272, #3313, #3185): Flag-gated, short-lived test identities for test Hubs (off by default), with provenance stamps, purge, a test-Hub banner and admin-tier startup gates. Agent delegation grants and credential exchange behind `hub.agent_delegation` (default off).

## 🔒 Security
* **Service account assign authority** (#3190, #3306): The Hub records who authorized each service account assignment and checks that the source still holds `gcp_service_account.assign` on that account. A same-role repair reincarnate re-records the assignment from the user only if they pass the gate.
* **Root commands use a fixed path** (#3268): `sciontool init` runs `groupmod`, `usermod` and `sed` through a fixed system search path instead of the inherited `PATH`.
* **Sign-in denial reasons** (#3241, #3298): Invite-only Hubs report `invite_only` instead of a domain error, and audit entries record the actual refusal reason.

## 🐛 Fixes
* **Runtime Broker Hub connections** (#3223, #3281, #3299, #3276): Start, stop and reinitialize run one at a time per connection, and a credential change takes effect after reinitialize. A stopped connection never restarts. Failed reinitializes retry with backoff up to 5 minutes. A component set up after startup takes effect without restart.
* **Harness auth and status** (#3303, #3242, #3296, #3344, #3264, #3273, #3333, #3225): Claude's Vertex AI guess no longer overrides an API key. A settings-only Copilot `config.json` is no longer treated as sign-in. Claude's Notification hook uses Claude notification types. A `waiting_for_input` status clears after the prompt is answered, and Codex sub-agent events no longer clear a held status. Copilot hooks read their stdin payload.
* **Agent homes and resume** (#3254, #3224, #3255, #3307): Resume keeps a populated agent home when `scion-agent.json` is missing. Restart repairs home ownership when the runtime uid differs. Branch and worktree lookups run against the project repository. Project delete removes the project-config directory.
* **Session metrics** (#3259, #3237): Late native usage is counted, and unknown fields in the session-metrics state file are kept.
* **PostgreSQL web chat** (#3245, #3302): Web chat tables resolve in the current schema, and thread-ID migrations run once the messages table exists.
* **Storage and delivery** (#3279, #3334): A failed copy no longer finalizes a partial Cloud Storage upload. Closing the message buffer waits for in-flight deliveries.
* **Telemetry tiers** (#3305, #3338): Hub telemetry defaults and policy apply as separate tiers at start and are no longer persisted into `scion-agent.json`.
* **Other** (#3239, #3222, #3238): Scheduled auto-suspend runs the ephemeral-workspace check. Delegation adoption revert accepts equivalent timestamps. The Discord bot reports denied project template reads.

## 🔧 CI & Infrastructure
* **Starter Hub TLS rotation** (#3125): Renewed certificates are installed and Caddy reloads on renewal, so it no longer serves an expired certificate.
* **CI** (#3227, #3261, #3308): A workstation smoke job covers server start, link and stop, and waits for the server and Podman to exit. `build-images.sh` shows the Cloud Build config steps it submits.
