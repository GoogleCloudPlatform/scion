# Release Notes (2026-10-09)

Logging moved to a single `SCION_LOG_LEVEL` control with debug off for agents, and the decision audit table was dropped. Conversation, DM and Cloud Storage access were tightened to their owning project and verified identity. `scion attach` now reconnects through the Hub preflight. `scion reset-auth --reissue-scopes` can repair agent credentials in bulk, and stopped agents' model and limits can be edited.

## ⚠️ BREAKING CHANGES
* **Decision audit table dropped** (#2986): Routine authorization decisions no longer write database audit records. On startup, the Hub runs `DROP TABLE IF EXISTS decision_audits` (irreversible; an ACCESS EXCLUSIVE lock on PostgreSQL). During a mixed-version rollout, old replicas may log writer failures. Mutation audits and history are unchanged.
* **Unified log level; agents no longer inherit debug** (#3034, #3058, #2950, #3044): `SCION_LOG_LEVEL` (with per-component levels such as `info,hub.auth=debug`) controls the server, CLI and `sciontool`. `SCION_DEBUG` is a deprecated alias. Agents no longer inherit `--debug`; use `scion start --agent-log-level`. `server.log_level` now applies at startup and on reload. `server.log_format` and the `SCION_TELEMETRY_DEBUG`/`LOCAL_*` variables are inert.
* **Diagnostic endpoint behind its own flag** (#3067): `/auth/debug` is served only with `scion server start --enable-debug-endpoints`. `--debug` no longer changes routes, and the flag is refused in hosted mode.
* **Unlabeled git projects resolve as clone-per-agent** (#3016): A git project with no workspace-mode label (or a raw `shared-plain` label) now gives each agent its own clone. Only `shared` selects the shared checkout. On a Runtime Broker without the NFS export mounted, existing agents start in a new clone, so push shared-checkout work first.
* **Non-interactive confirmations answer No** (#2920, #2949): Without a terminal, prompts never read stdin, and confirmations default to No unless `--yes` is passed. Prompt text goes to stderr, so `--format json` output stays one document, including `stop --all --rm` and local `delete`.
* **Admin status reports only Hub admins** (#3074, #3006, #3032): `GET /api/v1/auth/admin-status` returns `isAdmin` true only for Hub admins and super-admins. Admin nav items now follow page permissions. The Hub settings tab is shown only to super-admins.
* **Single-node `hub_name`** (#2983): `deploy.sh` now sets `hub_name` from `HUB_NAME`, which changes the Hub name in telemetry, health output, log filters and notifications.

## 🚀 Features
* **Attach reconnects through the Hub** (#2966, #3025, #2952, #2948): `scion attach`, `start -a` and `resume -a` send the Hub's PTY preflight before dialing and on every reconnect, and reconnect after retryable closes (4503 promptly, 4504/1011 with backoff). Conduit relay sessions have a lifetime cap (`server.hub.conduit.lifetime_cap`, default 3500 s) with a GoAway handoff.
* **Re-issue agent scopes** (#3009, #3043, #3068): `scion reset-auth --reissue-scopes` recomputes an agent's role and scopes from its delegating agent or user. `--all` does this for every delegated agent in a Hub, parents first, as a dry run unless `--apply` is given.
* **Edit stopped agents** (#3070, #2955, #2936): The model and limits of created, stopped, failed or suspended agents can be edited. `GET /api/v1/agents/{id}` reports which fields can change in each phase, and PATCH enforces it. Configure shows Branch and Message Mode read-only.
* **Long tasks from a file** (#2976): `scion start` and `create` accept `--task-file <path|->` (up to 96 KiB). The agent gets the full text at `~/.scion/task.md`.
* **Health dashboard** (#2938, #3042, #3078): A Needs attention panel comes first, followed by a Hub card listing every check. A configurable monitoring dashboard link (`server.hub.monitoring_dashboard_url`) appears on the page. Each Hub replica now registers itself in a new `hub_instances` table.
* **Artifacts, experimental** (#2930, #3054): Behind `hub.artifacts`: a Share dialog and `scion artifact share`, with a Shared with me filter. An agent's delegating user or a home-project admin can grant a human review access to agent-owned artifacts.
* **GCP identity** (#3000, #3021, #2999, #3052, #3048): `--service-account` accepts an ID, email or display name. Kubernetes agents with a `block` identity run as a zero-privilege service account instead of being refused. Missing or mismatched Kubernetes SA mappings return 400 `identity_not_mapped` / `identity_ksa_mismatch`. `scion list --format json`, `scion look` and agent detail show the agent's identity and verification status.
* **Flat Runtime Brokers, experimental** (#3045): Behind `hub.flat_runtime_brokers` (default off): one runtime target per Runtime Broker, with agents pinned to it across restarts.
* **Clone depth** (#2959): A `clone_depth` setting on profiles and templates (`full` or 1 and up) replaces the fixed depth-1 clone.
* **Kubernetes Go limits** (#2956): Agent pods get `GOMAXPROCS` and `GOMEMLIMIT` from their container limits.
* **Web** (#2957, #3065, #2934, #2997, #2937, #3020): Ctrl/Cmd+1-3 switch between dashboard, chat and terminals. A terminal can move to the current window from its owning tab. The new-agent form drops the create-only button, and a toast reports when an agent was created but did not start. Quick switcher rows show the project slug.
* **CLI** (#3057, #2941, #2940, #2920): Hub and machine-level commands run outside a project, and relayed Runtime Broker failures print a short category. `scion start` exits 0 when the Hub accepted a launch the CLI cannot follow. `--expires 1y` is always 365 days. A new guide covers using the CLI from a coding agent.
* **Groundwork** (#2922): Audit event catalog and emission contract. Runtime behavior is unchanged.

## 🔒 Security
* **Conversations stay in their project** (#3066, #2951, #3013, #3036): Conversations keep the project they were created in, and lists and lookups return only readable ones. Replies, attachments, read markers and thread references stay inside their conversation. Live DM events reach only participants, and live agent messages follow the message history visibility rule.
* **Cloud Storage links use verified identity** (#3028): `gs://` links in agent messages are fetched only when the agent's service account is verified, available to its project and still assigned.
* **Agent file deletion scoped to its project** (#3014): Deleting an agent's files no longer also removes a same-named agent in the global project.
* **Permissions** (#2990, #2968, #2979, #2932): Unchecked artifact permissions are reserved and kept out of grantable sets. Hub admins can list Hub-level env vars (secrets excluded). A user's same-role reincarnate repairs an unrecorded delegation chain, and delegation adoption retries legacy SQLite rows.
* **Less detail in errors** (#2929, #2946): Workspace sync failures send fixed client text and log details on the Hub. A canceled diagnostics stream ends without the credential event.

## 🐛 Fixes
* **Delete and create races** (#3075, #3062, #3024, #2989, #3030, #3031): An in-doubt delete whose queued intent later succeeds is finalized. Queued start and restart refuse an agent a delete holds. Create rollback never removes a row a delete holds. Deferred deletes run after a project delete and are fenced with `notAfter`. Managed deletes no longer ignore cloud cleanup errors. Project-scoped delete sends `force` and keep options.
* **Synchronous dispatch and relayed errors** (#2980, #3023, #2981): Other synchronous dispatch paths extend the write deadline, so slow dispatches no longer drop the connection. A Runtime Broker's 400 `validation_error` is relayed instead of 502. Hub-managed workspace storage paths are recorded before dispatch.
* **Settings saves keep fields** (#2964, #2995, #3001, #2931): A partial project settings PUT no longer deletes the default GCP identity. Telemetry and `agent_defaults` saves merge onto the stored row. More settings reach `SCION_SERVER_`/`SCION_SEED_` env names, and `server start --config` is honored. Legacy settings migration keeps `workspace_path`, `cli.mode`, `hub.transport`, `hub_connections` and `project_id`.
* **Session metrics** (#3022, #2939): Native usage (Claude, Copilot, Codex, Gemini) reaches persisted session metrics, and Copilot sessions with no session ID are reported under a stable fallback ID.
* **Provisioning and templates** (#3026, #3072, #2954, #2947, #3069): Template and harness-config resolution happens before any agent state is created. Inline config updates replace Hub skills with the complete list. Template repair resolves by ID. Reprovision replaces `prompt.md`, so no earlier task survives. Harness-config reimport validates `sourceUrl`. `scion create -p` sends the profile in Hub mode.
* **Runtimes** (#2960, #3002, #3041, #3037): Restart starts on the runtime the agent was found on. The Runtime Broker `?status=` filter works for local runtimes. Hung workspace mounts no longer leak a goroutine per health probe, and Cloud Run NFS mounts are validated against the share. Project sync excludes a bare root `.scion` marker.
* **Web terminals** (#3081, #3049, #3015): Hidden panes attach only once revealed, and the rail shows "Not opened yet". A silent socket times out on the initial connect. RECONNECTING shows during the jittered wait.
* **Web** (#3010, #2942, #3063, #2925, #3053): Agent message events no longer corrupt agent state. Agent DMs opened from a link restore fully. Thread defaults stored as IDs show the agent name. The create form omits GCP identity and telemetry unless chosen. Pull latest failures show readable text.
* **HTTP hygiene** (#3011, #3012, #2974, #3040): 405 responses send `Allow` across the Hub, conduit relay, artifacts, `sciontool` and extras, and the test sign-in handler returns JSON errors.

## 🔧 CI & Infrastructure
* **CI** (#3077, #2944, #2962, #3061, #3029, #3039, #3027, #2945): Web lint is a blocking gate after an ESLint 10 migration, and typecheck covers e2e configs. Postgres service images are pulled through `mirror.gcr.io`, and `pkg/hub` test compiles use lower GOGC. Starter-hub scripts are linted and tested, with debug off by default. Docs PR builds no longer cancel each other.
