# Release Notes (2026-11-23)

This day filled out agent-scoped secrets with create-time secrets, a web UI and agent-initiated requests, added `scion conversation watch`, and saved a suspended agent's last terminal screen. It also removed retired `scion message` flags and tightened agent container defaults.

## ⚠️ BREAKING CHANGES
* **Retired `scion message` flags are removed** (#5417): `--in`, `--at`, `--plain`, `--notify`, `--channel`, `--thread-id` and `--cc` no longer exist. Use `scion schedule create --in/--at` for delayed messages, `scion notifications subscribe` for notifications, conversation references instead of channels and threads, and body mentions instead of `--cc`.
* **Agent containers drop `CAP_NET_RAW`** (#5401): Docker and Podman agent containers run with `--cap-drop NET_RAW` in every metadata and network mode, so tools that need raw sockets, such as `ping`, no longer work inside agents.
* **Container-engine sockets can't be mounted into agents** (#5404): A Runtime Broker refuses any agent volume whose host source is or contains a Docker or Podman socket (rootful or rootless), whatever configuration sets it.
* **Re-registering an online broker needs `--force`** (#5373): Re-registering a Runtime Broker that is online is refused with 409 unless you confirm with `--force`. Join-token re-mints that keep settings are exempt.

## 🚀 Features
* **Agent-scoped secrets: create time, web UI and requests (experimental)** (#5374, #5386, #5413): Under `hub.agent_secrets`, agents can be created with secrets from `--secrets-file`, and the web UI manages agent-scoped secrets on the agent and create pages. An agent can request secrets from a user, who fills or dismisses the request from a card in chat or a standalone form. Values are stored at agent scope and are never shown back. Agents list or withdraw their requests with `scion secret request`.
* **`scion conversation watch`** (#5310, #5400, #5414): Waits for new messages in a conversation, once or as a continuous stream, with retries and several output formats including NDJSON.
* **Last terminal screen of suspended agents** (#5304, #5410): With `hub.suspend_screen` (alpha, on by default), the Hub captures an agent's visible terminal when it is suspended. `scion look` shows that screen for a suspended agent, and the web terminal offers a Resume button and reconnects automatically.
* **Inbox dashboard (experimental)** (#5427): Behind `web.inbox_dashboard`, the web UI has an inbox that gathers items waiting on your approval.
* **Exec output capture** (#5428): An exec schedule or event can opt in to capturing its output. `json` keeps stdout up to 64 KiB as validated JSON. By default output is still discarded.
* **Admin-managed brokers only (experimental)** (#5333): With `hub.admin_managed_brokers` and `broker_policy.admin_managed_only` on, only admin-managed Runtime Brokers (embedded, auto-provided or approved) are used for agents.
* **Template and image provenance** (#5423, #5430, #5365): Imported templates record their source commit, and each agent records the source URL and commit of the template it was created from. `scion doctor` reports agent image capabilities and version skew. Agents can read the Hub's ID from `GET /api/v1/agent/hub`.
* **Trusted proxies for client addresses** (#5403): `server.trusted_proxies` now also decides whose `X-Forwarded-For` the Hub trusts for per-IP rate limits and audit records. The Helm chart exposes it as `hub.trustedProxies`.
* **Web UI additions** (#5357, #5359, #5366, #5358, #5416, #5411, #5309): Recorded decisions show their offered choices and recommendation. The branding page has an advanced palette editor. There's an admin page for System One providers. Artifact review drafts show their status and can be resumed. Detail pages have breadcrumbs. On mobile the chat quick switcher's search sits at the bottom. Forced `rebuild-server` maintenance runs are audited and shown in the UI.
* **Release binaries in images and on GitHub** (#5425, #5421, #5406): Image builds can install the `scion` and `sciontool` release binaries from GitHub, `sciontool` for Linux is published as a release asset, and `scion init` suggests the `ghcr.io/homebrew-scion` images.
* **GitHub triggers (experimental)** (#5334, #5385, #5429): Dispatched agents can get a GitHub installation token. Triggers can reuse subjects, coalesce events within a window and refuse stale events.

## 🔒 Security
* **Network and metadata hardening** (#5426, #5412, #5435, #5418, #5419): Metadata-server probes are verified with deadlines and IPv6 blocking. The Claude init firewall drops IPv6, pins the gateway as a /32 and makes SSH opt-in. The network-setup container's lifecycle is hardened. The firewall no longer allows `statsig.anthropic.com` and tolerates optional hosts that don't resolve.
* **Access and isolation fixes** (#5375, #5399, #5395, #5384, #5389, #5371): Project-scoped agent reads return 404 when access is denied. Agent config `PATCH` merges `env` by key and enforces the attach permission. Execution containers isolate identities and logs and fail closed. Discord callbacks check channel permissions and project membership. Agent log relays read only regular files without following links. Agent schema validation limits recursion depth.

## 🐛 Fixes
* **Schedules follow deleted agents** (#5360, #5409, #5398): Deleting an agent cancels pending one-shot events that target it or were created by it, and pauses recurring message schedules that target it. Soft-deleted agents are rejected as targets. The default cap on active recurring schedules per project is raised to 100.
* **Lifecycle** (#5422, #5407, #5432, #5347, #5368): Resume and restart prompts carry the agent's earlier completion status. An agent started without a prompt moves to idle once it is ready. Submitting an artifact review wakes or confirms a suspended agent's owner. Suspend and stop clean up more reliably, and a failed reincarnation restores the delegation edge.
* **Hub and broker** (#5379, #5392, #5380, #5381, #5396, #5376, #5424, #5405): `/readyz` waits for the artifact store and returns `Retry-After` during startup. The metrics dashboard uses the saved GCP project ID. Usage endpoints count matching quota scopes. Template slugs resolve project, then user, then global, as the CLI does. Default GitHub permissions match capped minting. Podman and Apple container pull failures and unreachable runtimes are classified.
* **CLI and chat** (#5377, #5364, #5450, #5378, #5356, #5388, #5394, #5402, #5438): `harness-config sync` and `push` take `--scope`. Notification commands accept short ID prefixes. Messages can be sent with only attachments. Bare numbers and hex strings are no longer read as mentions. Chat keeps session and commit prefixes intact, links `gs://` paths, and fixes thread, panel and dialog state issues.
* **Setup** (#5249, #5295, #5387): Starter-hub installs root-owned binaries and service files. Onboarding starts the co-located broker without a registry and checks the runtime daemon. The Copilot CLI version is pinned.
