# Release Notes (2026-11-21)

This was a large hardening day of about 190 commits. Hosted Hubs now refuse development shortcuts, recurring schedules get limits, lifecycle hooks run with a filtered environment, and several authentication paths were tightened. It also added Hub branding controls, template import from a URL, custom default user roles, single-choice and "Other" decisions, and more GitHub trigger capability.

## ⚠️ BREAKING CHANGES
* **Recurring schedules have limits** (#5275): New `server.hub.schedules` limits apply whenever a recurring schedule of any kind is armed: on create, cron change, enable or resume. `min_interval` (default 5 minutes, `0s` turns it off) refuses with 400 a cron expression that can fire more often. `max_active_per_project` (default 50, 0 turns it off) refuses more active schedules with 429 `quota_exceeded`. Schedules that are already active keep running. A paused schedule that breaks a limit must be edited before it can be resumed. Schedule creators can now stop their own schedules.
* **Hosted Hubs refuse development shortcuts** (#5233, #5255): A hosted server (`--hosted` or `server.mode: hosted`) refuses to start with dev auth enabled from any source, and refuses `--enable-test-login`, except on a designated test Hub. Archive URLs that redirect, such as GitHub archive links and release assets, are refused on a hosted Hub, so give the final URL.
* **The Hub's own GCP service account can't be an agent identity** (#5229): Registering, verifying, assigning or minting tokens for the Hub's own service account now fails with 400 `identity_reserved`. A startup scan marks existing matching rows as failed. Use a dedicated service account for agents.
* **Lifecycle hooks get a filtered environment** (#5185): `pre-start`, `post-start`, `pre-stop` and `session-end` hooks no longer see variables that came from a harness config (`env`, `env_template`, `no-auth-env.yaml`, `harness_configs.<name>.env`). Those go only to the workload. Interpreter, loader, shell and git override variables (such as `LD_*`, `PYTHONPATH`, `NODE_OPTIONS`, `GIT_CONFIG*`) are always withheld. Hub, operator and secret variables such as `GITHUB_TOKEN` are still passed. Startup git commands run with a minimal environment.
* **Downgrade floor raised to `nightly-20261120`** (#5205): The Hub refuses update targets older than `nightly-20261120`.

## 🚀 Features
* **Hub branding controls** (#5284, #5231, #5252): Admins have a branding settings page. Branding gains a corner style (default, square or rounded) and `server.hub.branding.font_sans` for the UI font.
* **Template import from a URL** (#5239, #5153): `scion templates import-url <github-url>` imports templates from a GitHub folder URL on the Hub, using the target scope's Hub secrets, and skips templates whose content is unchanged. `scion templates update` takes `--scope`, and in agent mode an agent can refresh a project template only from its stored source URL, with `--url` overrides refused. Template agent configs can be checked against the schema on every import (behind an experiment), and import and sync warn about invalid ones.
* **Custom default user role (experimental)** (#5240, #5251, #5273): Behind `hub.custom_default_user_role`, `server.auth.default_user_role` can name an eligible custom system-scope role. Its grants are applied when users are provisioned and reconciled, and admins can set it in the web UI.
* **Single-choice and "Other" decisions (experimental)** (#5299, #5192, #5203): Under `web.decisions`, a decision can offer a single choice, shown as one confirmation button. "Other" answers appear for agents, in the CLI, in search and on the Made tab. Agents are guided to keep questions and choices short, and the CLI warns about long ones.
* **Default message mode for new agents** (#5279): `server.hub.default_message_mode` sets which users and agents may message a new agent (`none`, `lineage`, `branch`, `project` or `hub`). The built-in default stays `project`.
* **Clearer suspend and stop notifications** (#5171, #5234, #5242): An auto-suspended agent's notification names the reason and threshold. An agent's creator is notified when someone else suspends or stops it, without duplicate or stale notices.
* **GitHub triggers act on GitHub (experimental)** (#5219, #5197, #5232, #5190, #5228): Behind `hub.github_triggers`, a trigger can post a GitHub comment and replies to unmatched commands. Triggers pause when the App loses a repository, gain a CLI, can skip a dispatch based on subject claims, and see pull request comment details in CEL. Rule compilation has a budget.
* **Agents publish skills in their own project** (#5290): An agent can publish skills in its own project's scope.
* **Smaller additions** (#5151, #5057, #5020, #5119, #5257, #5106, #5282, #5268, #5266): `scion artifact publish --expires-in` sets an artifact's retention at publish time. `scion harness-config show` and the API include harness capabilities. `scion sa mint` takes `--json`. Behind `hub.artifacts_review_drafts`, in-progress artifact reviews are saved as private drafts. In the web UI, status badges have accessible tooltips and show agent-reported status, the header has a Terminals dropdown at every width, project skills have a searchable project filter, and back links name the project.

## 🔒 Security
* **Tighter token and identity checks** (#5308, #5307, #5316, #5318, #5235, #5237): Bearer authentication requires an access or CLI token type and an `exp` claim. Delegation applies the project-scope rule to every grant type. Agent delegation standing is checked at Conduit admission, relay rechecks and auth refresh. Google service account tokens on the external bearer path must match `allowed_emails` when it is set. For OIDC providers whose userinfo omits `email_verified`, such as Microsoft Entra ID, the Hub verifies the email from the ID token.
* **Safer file and asset serving** (#5125, #5260, #5271, #5296, #5164, #5277, #5267, #5276): Hub workspace and attachment file opens refuse non-regular files through one shared helper. Static asset paths are normalized before routing, untrusted content is served with `Referrer-Policy: no-referrer`, and the chat attachment blocklist covers more Windows extensions and normalizes stream suffixes.
* **GCP metadata and secrets fail closed** (#5246, #5314, #5259): Docker and rootful Podman install metadata-server interception through a network-setup sidecar, and handle broker/image version skew. Secret Manager lookup errors other than not-found now fail instead of being treated as missing.
* **Other hardening** (#5135, #5265, #5248, #5172, #5250, #5270, #5134, #5160, #5253): Default GitHub App token permissions are intersected with what the App was granted. Hub-supplied keys are stripped from cached plugin config. Telemetry applies its mandatory redaction to native field aliases. A2A bridge task routes authenticate under federation. gcsfuse mount arguments are quoted. Unauthenticated broker audit records go to a reserved sink. A deprecated CSV import body is capped at 2 MiB. Boundary deletes check their revision atomically. Starter-hub rebuilds validate their install source.

## 🐛 Fixes
* **Status accuracy** (#5129, #5131, #5291, #5224, #5298): The stall cutoff is longer while an agent is thinking, and sciontool reports thinking after a tool call ends. An agent-set `ask_user` keeps the agent waiting for input until its turn ends. The web UI shows Delivery unconfirmed when a dispatch outcome is unknown, and warns when replying to a deleted agent.
* **Starts and brokers** (#5063, #5154, #5138, #5174, #5109, #5061, #5236, #5238): A start claim is released right away when dispatch fails before connecting or with a 4xx. A deregistered broker returns a terminal `broker_deregistered` error and isn't retried. A running container is reused only if its `agent_id` label matches. The resolved runtime profile is recorded at create. `--broker` accepts unique name and slug prefixes. Docker image pull failures are reported as an `image_pull` step. Broker limit refusals (429) explain which phases count.
* **Cloud Run** (#5123, #5112, #5272, #5200, #5204): Cloud Run Instances use the platform defaults of 2 vCPU and 2 GiB when no resources are set. Instance reuse now notices changed container resources and working directory. Storage errors name `server.project_storage`.
* **CLI** (#5133, #5110, #5003, #5001, #5017, #5087): Conversation references, message display, wake reasons and group names are clearer. Agent mode exits non-zero for gated or unknown subcommands, as do `scion conversation` and `sciontool status` with unknown input. In a container, `SCION_PROJECT_ID` wins over workspace project files. `server start` creates a missing `~/.scion`.
* **Smaller fixes** (#5066, #5217, #5218, #5034, #5225, #5294, #5189, #5196, #5143, #5048, #5223, #5226, #5199, #4986, #4988, #5072): Direct user notifications are kept in the inbox. Azure DevOps clone URLs are normalized. Concurrent Kubernetes shared-directory volume claims no longer fail. Copilot keeps installed plugins across an auth rewrite. Substrate bootstrap files are built before the actor is created. Admin settings saves validate the server blocks checked at startup. GitHub App setup updates an existing installation and keeps stored repositories when discovery fails. Shutdown drains background work, and chat endpoints do less work per refresh. *(Contributor for #5225: a)*
